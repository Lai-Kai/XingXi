# 导入文献后自动生成并扩展关系网

用户期望持续通过产品导入新文献、解析并抽取关系，而非每次修改代码或人工拼接知识版本。

## 验收

- 上传界面提供默认开启的内部解析和待复核图谱生成选项；登记来源、选文件并上传即可进入后台流程。
- 已上传资料有“生成图谱”入口，无需重新上传或伪造人工复核结论。
- 内部处理选择保存来源授权审计，不修改版权结论，不赋予公开引用权限，不覆盖撤销或过期策略。
- 后台复用解析/OCR/清洗/分块结果，幂等创建 Evidence、主体和关系；失败可重试。
- 新文献自动进入累积内部工作版本，准备全文索引和图谱/地图资产后才切换版本；保留有当前版本精确证据的早期内部关系。
- 主体与关系继续待复核；公开版本维持原有审核和授权门禁。
- 用真实 HTTP + SQL + worker 的合成测试证明两本文献先后上传产生独立关系网并保留旧关系，无需修改测试运行期间的配置或知识代码。

## 范围说明

复用现有的确定性关系抽取器，支持其可识别的明确关系句。当前不是新增大模型通读理解能力，也不承诺任何文献都能抽出关系。原始文本、Evidence 和待复核状态是关系候选的依据。
