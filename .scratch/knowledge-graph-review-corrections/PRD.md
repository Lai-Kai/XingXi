# 知识图谱关系与事件审核纠错

修复审核后入口消失、驳回记录不可发现、缺少审核历史的问题。

四种状态允许任意不同状态之间转换；当前状态不提供操作。首次待复核转通过可不填写备注，驳回、争议和修改已有结论必须填写备注，无 Evidence 不能通过。失败保留当前状态，成功采用服务端记录。

管理员通过显式 include_rejected 查询读取驳回记录；普通查询、工具及普通用户排除驳回内容。前端驳回关系使用独立审核列表，并保留页签、筛选和改判入口。

每次实际状态变化在同一事务中追加不可变审核记录。复用现有追加历史模式，新增最小表，不改写既有 Release、激活指针和资产快照。

验收：真实 SQL/HTTP 测试覆盖十二种转换、权限、备注、Evidence、回滚、并发、历史不可改写及迁移；前端单测和可变 mock Playwright 覆盖状态/筛选/缓存、关系事件连续改判、失败与刷新。
