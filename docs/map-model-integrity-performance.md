# 地图模型完整性与预览性能

2026-10-25 第一、二轮改进；部署与实测证据随本轮交付报告保存。

## 点位绑定与分页

- 重建请求提供 `point_id` 时，服务端从共享的静态、Release 和自建点位目录取得名称与 `entity_id`；未知点位返回 404，素材保存及 SSH 提交均不会开始。未提供点位的独立重建仍可使用，但不会采用浏览器填写的名称或实体建立地图绑定。
- 模型目录新增 `GET /api/map/model-assets/page?limit=100&point_id=...&cursor=...`，返回 `{data,next_cursor}`；每页 1–200 条，按 `created_at DESC,id DESC` 排序，游标绑定点位筛选。SQL 在限量前过滤完成状态、有效产物和当前点位实体，路由补足被损坏历史描述剔除的候选。
- 原数组接口保持兼容，取消静默只读前 1000 个任务的限制。历史记录仅在缺失 `entity_id` 字段时保留旧版兼容，显式 null 或错误实体不通过。
- 前端专用转发允许 `/page`；客户端支持逐页读取、点位过滤、中止、按 ID 去重和重复游标报错。全图 3D 标记目前仍每 15 秒聚合目录；分页消除遗漏，不代表已实现海量目录按视区加载。

## PLY 完整性

上传和新 SSH 任务共用 Python 3.8 标准库验证器。ASCII、大小端二进制均验证声明记录、列数、类型范围、有限数值和截断；头部上限 64 KiB、ASCII 单行 1 MiB、属性 256 个，分块读取。完整 Gaussian 至少含 `f_dc_0..2`、`opacity`、`scale_0..2`、`rot_0..3`，RGB/Alpha 保留原始字节与下载哈希。新任务会上传验证辅助文件，已有任务的只读 inspector 不依赖该文件。

这属于文件可读性检查，不增加几何重绘、跨视角结构或视觉质量拒绝规则。

## 预览与地图

- RGB PLY 在独立 Worker 中顺序解析，转移输入和结果缓冲，取消时终止实际解析；默认均匀采样至最多 30 万点。完整模式最多 500 万点，切换时重新读取源文件，避免常驻两份大输入。完整边界仍用于取景，sRGB 转线性颜色和文件 Alpha 独立保留，原文件下载不变。
- 点云及 Gaussian 预览按需渲染：交互、尺寸变化和 Spark 异步结果唤醒；空闲、隐藏或离屏停止调度。退出销毁 WebGL、控制器、几何、材质、监听器和观察器。放大仍移动同一画布。
- 预览默认轻量模式的 DPR 上限为 1.25，完整模式为 2。Gaussian 轻量模式降低画布精细度，保留全部高斯。
- 地图均衡模式 DPR 上限 1.5；“图层”中的“地图流畅模式”上限为 1，并关闭浮层模糊，偏好保存在本机。拖动时暂停浮层模糊，后台页停止时间轴播放。保持 OSM 完整色彩、归属标注、点位含义和七个原 GLB 精确绑定。

## 验证边界

使用确定性 RGB/RGBA 和完整 Gaussian 软件夹具验证解析、渲染、精度切换、空闲停帧及释放。CPU 假引擎可验证真实 SSH 的文件与任务链路；这不替代真实 GPU 重建质量验收。性能比较必须注明浏览器、实际 WebGL 渲染器、DPR、相同场景和网络夹具；不把画布像素减少换算成用户设备的固定帧率承诺。数据库迁移版本和账号策略不属于本轮变更。
