# 地图高斯离散点显示

用户需要看到每颗高斯中心的位置。地图三维研习、本地 PLY 和影像重建共用的原生查看器新增“显示方式”，提供“高斯渲染”与“离散点”；“预览精度”继续单独保留。离散点可调 1–6 px，以实心彩色圆点显示原生模型的全部中心，不模拟椭球与透明叠加。颜色取自解码后的基础颜色，不包含随视角变化的高阶球谐效果。

两种方式复用已下载并解码的同一模型、相机和画布。按需生成离散点，分批让出主线程并响应取消；切回高斯时复用原渲染对象，切换页面释放资源。不会覆盖下载文件或改动训练产物，也不会把独立 RGB 副本自动替代为原生高斯。
