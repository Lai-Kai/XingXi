# Domain docs

Xingxi is currently a single-context product repository.

## Read before changing domain behavior

- `../PROJECT_PLAN.md` is the current source of truth for product vocabulary, phase boundaries, acceptance criteria, and execution status.
- Read root `CONTEXT.md` if one is added later.
- Read relevant records under `docs/adr/` if that directory is added later.

Use the plan's terms such as SourceDocument, SourceFile, parsed document, page, paragraph, Chunk, Evidence, and review status consistently. If a future ADR conflicts with the plan, surface the conflict rather than silently choosing one.
