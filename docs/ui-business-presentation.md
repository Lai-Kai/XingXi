# 产品界面业务表达

按用户要求，产品页面隐藏内部模型和服务名称、调用过程、推理、用量、运行编号、哈希及原始诊断错误。前端继续使用原有接口与数据身份，不改变授权、审核、来源及许可语义。

- 聊天只显示用户提问、最终回答、中性处理提示、合法澄清卡片、附件及出处。恢复的用量偏好不能打开技术信息；最终回答附带的思考也不显示。延迟工具结果、附件调用进度和无法解析的澄清结果不能回显原文。默认导出排除工具调用中的服务说明。
- 设置使用研究能力、辅助功能、研究方式等功能称呼。未知内置条目采用稳定的业务回退名称；用户自己填写的内容保留。服务异常和安装结果使用固定提示。
- 资料页隐藏内部编号与哈希，异名辨析通过查找真实原文选择出处。普通读者可访问受详情接口授权的出处，上传、发布及复核权限仍由原有门禁控制。
- 地图隐藏生成算法、服务日志及底层模型名，保留文件选择所需的格式、来源、许可与待核验状态。
- 问答评测保留题目、回答、规则结论、引用和复核，但隐藏工程参数与运行身份。预设流程检查仍明确不衡量实际回答质量。定时任务通过对话标题选择目标，已有特殊时间安排保留原值。

## 验证

对应单元测试与浏览器回归位于 `frontend/tests/`。本次运行环境不允许监听 `127.0.0.1`，Rstest 在启动端口探测时返回 `listen EPERM`，因此不能声称常规单元套件或浏览器交互已通过。

无端口验证脚本位于 `.scratch/ui-business-presentation/`：`verify-chat.cjs` 覆盖中英文真实聊天组件渲染、合法澄清、附件、延迟工具消息、思考、已保存用量偏好及默认导出；`verify-settings.cjs` 验证中英文设置渲染和真实开关状态。各模块另完成资料权限分支与评测详情的离线渲染检查。类型、ESLint、格式与差异空白检查独立执行。

这些改动需要重新构建并启用前端版本后才会体现在现有部署中；本次未重启或切换线上服务。
