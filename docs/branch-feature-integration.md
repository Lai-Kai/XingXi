## 已接入的功能

### 对话内史料考据

点击回答引文或折叠来源列表中的出处，可在当前对话查看实际书名、版本、卷页、
原文和复核状态。对话顶部“史料考据”可汇总可见 AI 回答的引用并统计重复次数；
隐藏控制消息、用户输入和代码示例不会成为出处列表。详情仍由现有授权 API
返回，打开面板本身不请求原文。

1280px 及以上显示侧栏，其他宽度使用抽屉，手机使用底部抽屉。关闭后可继续
研究；附件和辅助对话面板具有显示优先级。切换会话清除所选出处，Provider
不通过 React key 重挂载聊天子树，保留首条消息创建会话后的连续发送。

Evidence 链接在 Markdown URL 清理之前转成规范文献库路径，解决自定义协议
被渲染器清掉的问题。危险 URL 仍受原有清理策略限制，普通外链、新标签页和
修饰键点击保留其导航行为。无考据 Provider 的页面继续进入文献库。界面使用
当前语义颜色，并保留聊天的渐变背景。

### 定时研究模板

`/workspace/scheduled-tasks` 的快速创建提供四个模板：每日地图史料线索、地图
点位考据、古今地名核对、每周地图研习简报。前三个默认每日 09:00，简报默认
周一 09:00；时区继续由原表单识别，用户可修改。

标题、说明和提示词一起本地化。选择模板只填充草稿，明确点击“创建”后才
调用原有创建 API，后台运行仍需 `scheduler.enabled`。模板要求引用实际资料，
不能核实的更新时间、坐标、点位或复核状态必须说明未知；不自动修改地图或
发布知识。它们是研究提示模板，不新增地图数据读取工具。
