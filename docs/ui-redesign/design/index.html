依据入库文献《清实录·高宗纯皇帝实录》与民国《吴县志》载录，乾隆皇帝十六年（1751）首次南巡即驻跸木渎。

其行馆主要设于灵岩山麓之 [文献:木渎镇志 卷三] ，即徐氏别业（后为虹饮山房 [文献:吴县志 艺文考] ）。乾隆帝曾在此驻跸并赐诗题额。后历次南巡（二十二年、二十七年、三十年、四十五年、四十九年）均以此为行宫别苑。

⚠️ 考据提示： 民间相传严家花园前身沈氏羡园亦曾设接驾行馆，但查阅现存乾隆朝起居注，未见正式驻跸明文，仅作游憩经停记载。
