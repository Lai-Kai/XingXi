# Batch 4 — 管理与专业业务页面

日期：2026-10-15。采用 Gemini v1.1.0；本批按用户指定范围实施文献库、知识图谱、质量中心、Agent 评测、运营中心与定时任务六页。项目、展签、异名、登录及其余次级页面不在本批完成声明内。

## 页面与职责

| 页面 | 实施内容 | 保留的业务边界 |
| --- | --- | --- |
| 文献库 | 卷册目录卡、搜索与资料状态、批选、原件／入库进度、当前生效版本摘要 | 来源登记、上传、导入、编辑、项目关联与 Evidence 深链接仍走原接口 |
| 人工复核 | 大幅宽屏工作台、原始文本／原件影印切换、右栏清洗文本、按页／按片段、复核历史 | 退回／争议意见必填，精确页面代次和 ChunkSet 不变；完成复核不等于发布 |
| 知识版本 | 主题统一的发布工作台、真实当前版本摘要与清单哈希 | active 指针与版本状态共同确定生效版本；保留 expected_state_version、准备／失败／重试／回滚语义 |
| 知识图谱 | 全图浏览、分类节点与争议关系样式、管理画布和右侧审核窗 | 默认全图保持只读浏览；有权限者主动打开专业工作台，manage=1 可刷新恢复；实体／关系／事件审核沿用原模型 |
| 质量中心 | 五列反馈记录、桌面核对栏、手机底部处理窗、保存失败保留意见 | quality:read 与 quality:review 分离；仅链接真实原会话，不编造回答快照 |
| Agent 评测 | 治理流程引导、语义主题、KPI／筛选／趋势／轨迹详情的明暗适配 | 批次指标范围、真实终态通过率、缺失耗时、回放／重跑／复核／导出保持原义 |
| 运营中心 | 指标卡、真实热门实体横条、回归／纠错／版本面板主题 | 缺失率显示不可用，未接入的三维统计不造成功率或趋势 |
| 定时任务 | 任务统计、任务记录与创建表单双列，窄屏按顺序排列 | 原时区、计划、配方、上下文模式、暂停／恢复／触发／删除及运行记录不变 |

## 公共表现层

- `components/workspace/admin-workbench.tsx` 提供流程引导、注明范围的统计卡和真实知识版本摘要。统计接口失败显示不可用，不用 0 代替未知。
- `styles/xingxi-admin.css` 集中管理卷册、复核、图谱、质量与任务布局，手机统计两列、触控控件至少 44px。继续使用已落地的语义 Token，不手改生成组件。
- `components/workspace/source-facsimile.tsx` 通过受保护的 source-file content URL 显示已上传图片或 PDF。PDF 使用物理页码定位；图片是原文件。当前 ReviewQueue 没有独立 OCR 页图／区域坐标，因此不生成页图、OCR 框或假切片定位。失败时保留打开原件入口。
- 质量保存后刷新保留已显示的列表 DOM，手机关闭弹窗能回到原按钮；保存失败留在详情中显示错误，不丢掉填写内容。
- 图谱普通全图使用自己的 overview 统计；管理目录统计只在专业工作台展示，避免并排出现来自不同请求的矛盾数字。
